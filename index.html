MindSift Flatpak repository

The MindSift desktop app for Linux (x86_64) as a Flatpak, with updates through GNOME Software, KDE Discover or flatpak update. Latest release: v0.99.4. The runtime (GNOME Platform) comes from Flathub.

Install

Open app.mindsift.MindSift.flatpakref with your software center, or run:

flatpak install --user https://flatpak.mindsift.app/app.mindsift.MindSift.flatpakref

Or add the repository and install from it:

flatpak remote-add --user --if-not-exists mindsift https://flatpak.mindsift.app/mindsift.flatpakrepo
flatpak install --user mindsift app.mindsift.MindSift

Run it with flatpak run app.mindsift.MindSift or from your app menu. Updates: flatpak update.

Signature

Commits and summary are signed with the key mindsift.gpg (fingerprint AFF88FCC8EA95FE897DAC57555173D35F6892584); both files above carry it, so Flatpak checks every download.
